## 📊 Customer Shopping Behavior Analysis

# Overview

This project focuses on analyzing **customer shopping behavior and purchasing patterns** using Python, NumPy, PostgreSQL, and Power BI.
The project follows an end-to-end data analytics workflow, including data loading, data cleaning, exploratory data analysis (EDA), SQL analysis, and interactive dashboard development.

# Project Objectives
* Understand customer purchasing behavior
* Identify sales and purchasing trends
* Analyze customer demographics and preferences
* Identify top-performing products and categories
* Answer business questions using SQL
* Build an interactive Power BI dashboard
* Generate meaningful business insights

# Dataset
The dataset contains customer shopping and transaction-related information, including:
* Customer ID
* Age
* Gender
* Category
* Item Purchased
* Purchase Amount
* Review Rating
* Discount Applied
* Subscription Status
* Payment Method
* Shipping Type
* Previous Purchases
* Purchase Frequency
The dataset was loaded into Python for data exploration and preprocessing.

# Project Workflow

 1. Data Loading
The dataset was loaded into Python and inspected to understand its structure and contents.
The initial analysis included:
* Checking rows and columns
* Understanding data types
* Checking missing values
* Checking duplicate records
* Understanding the dataset structure

2. Exploratory Data Analysis (EDA)
Exploratory Data Analysis was performed to understand customer behavior and identify patterns and trends.
The analysis focused on:
* Customer demographics
* Product categories
* Purchase amounts
* Customer ratings
* Purchasing frequency
* Payment methods
* Discount usage
* Subscription status
* Customer purchasing patterns

3. Data Cleaning
The dataset was cleaned and prepared for further analysis.
Major activities included:
* Handling missing values
* Removing duplicate records
* Correcting data types
* Standardizing inconsistent values
* Handling data inconsistencies
* Creating useful columns for analysis

4. SQL Data Analysis
The cleaned dataset was imported into **PostgreSQL** for further analysis.
SQL queries were used to answer important business questions and extract meaningful insights.
 Key SQL Analysis :
* Total sales analysis
* Category-wise sales analysis
* Product performance analysis
* Customer demographic analysis
* Gender-wise purchasing behavior
* Payment method analysis
* Customer subscription analysis
* Discount analysis
* Rating analysis
* Top-selling products
* Top 3 most purchased products within each category
